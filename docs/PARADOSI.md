## 2. Ανέβασμα στο Vercel (δωρεάν)

1. Μπαίνεις στο https://vercel.com με τον λογαριασμό GitHub.
2. **Add New → Project →** επιλέγεις το repo `kostastsikalas/andromidas_ioannis` **→ Import**.
   Το Vercel αναγνωρίζει μόνο του ότι είναι Next.js, οπότε δεν αλλάζεις καμία ρύθμιση.
3. Στο **Environment Variables** βάζεις τις τιμές της ενότητας 3α και μετά πατάς **Deploy**.
4. Παίρνεις ένα link της μορφής `andromidas-ioannis.vercel.app`. Αυτό το στέλνεις στον γιατρό
   για έγκριση.

Από εκεί και πέρα, κάθε `git push` στο `main` ενημερώνει αυτόματα το site.

## 3α. Διαχείριση άρθρων και ανακοινώσεων (`/admin`)

Ο γιατρός μπαίνει στο `/admin` με κωδικό και προσθέτει, αλλάζει ή διαγράφει άρθρα, μαζί με
φωτογραφίες, και ανακοινώσεις για την αρχική σελίδα (π.χ. άδειες, αλλαγές ωραρίου). Μια
ανακοίνωση μπορεί να έχει ημερομηνία λήξης, μετά την οποία κρύβεται αυτόματα. Οδηγίες για τον ίδιο: `docs/ODIGOS-GIATROU.md`.

Στο Vercel δεν μπορούν να αποθηκευτούν αρχεία στον server. Γι' αυτό κάθε αποθήκευση γίνεται
**commit στο GitHub repo**, και το Vercel ξαναχτίζει αυτόματα το site σε 1–2 λεπτά. Έτσι κάθε
αλλαγή κρατιέται και στο ιστορικό του git ως backup.

1. Στο GitHub: **Settings → Developer settings → Fine-grained tokens → Generate new token**.
   - Repository access: **Only select repositories** → `andromidas_ioannis`
   - Permissions: **Contents → Read and write**
   - Expiration: έως 1 χρόνο, με υπενθύμιση για ανανέωση.
2. Στο Vercel, στο **Settings → Environment Variables**, προσθέτεις:

| Όνομα | Τιμή |
| --- | --- |
| `ADMIN_EMAIL` | `ioannisandromidas@gmail.com`, ο μόνος λογαριασμός που μπαίνει στο `/admin` |
| `ADMIN_PASSWORD` | ο κωδικός του γιατρού (τουλάχιστον 8 χαρακτήρες, ιδανικά 12+) |
| `ADMIN_SECRET` | μια μεγάλη τυχαία φράση (προαιρετικό, υπογράφει το cookie σύνδεσης) |
| `GITHUB_TOKEN` | το token του βήματος 1 |
| `GITHUB_REPO` | `kostastsikalas/andromidas_ioannis` |
| `GITHUB_BRANCH` | `main` |

3. **Redeploy**, και μετά δοκιμή: σύνδεση στο `/admin`, ένα δοκιμαστικό άρθρο και μία
   δοκιμαστική ανακοίνωση, έλεγχος ότι εμφανίζονται, διαγραφή.

Χωρίς `GITHUB_TOKEN`, η διαχείριση στο live site επιτρέπει μόνο ανάγνωση και εμφανίζει σχετικό
μήνυμα. Τοπικά (`npm run dev`) οι αλλαγές γράφονται κατευθείαν στα αρχεία του φακέλου.

> Αν αλλάξεις κάτι στον κώδικα, κάνε πρώτα `git pull`, γιατί ο γιατρός μπορεί να έχει
> προσθέσει άρθρα από το admin (αυτά είναι commits στο repo).

## 4. Σύνδεση του domain (όταν εγκριθεί)

1. Στο Vercel πηγαίνεις **Settings → Domains → Add** και προσθέτεις το `ioannisandromidas.gr`
   και το `www.ioannisandromidas.gr`.
2. Το Vercel δείχνει ποιες εγγραφές DNS χρειάζονται, συνήθως μια **A** για το `@` και μια
   **CNAME** για το `www`. Τις περνάς στον πάροχο του domain, **ακριβώς όπως τις δείχνει το Vercel**.
3. Πριν αλλάξεις οτιδήποτε, κρατάς σημείωση με όλες τις υπάρχουσες εγγραφές DNS. Δεν σβήνεις
   εγγραφές MX ή TXT, γιατί μπορεί να αφορούν email.
4. Το παλιό WordPress hosting το κρατάς ενεργό για 1–2 εβδομάδες μετά την αλλαγή, για ασφάλεια.

Τα παλιά links του WordPress (`?page_id=...`) κάνουν αυτόματα μόνιμο redirect στις νέες
σελίδες. Έτσι τα αποτελέσματα του Google και οι σελιδοδείκτες συνεχίζουν να δουλεύουν.

## 6. Πού αλλάζει το περιεχόμενο

Όλα τα κείμενα είναι στον φάκελο `src/content/`:

| Τι | Αρχείο |
| --- | --- |
| Τηλέφωνα, email, διεύθυνση, ωράριο, περιοχές (τα αλλάζει και ο γιατρός από το `/admin`) | `clinic.json` |
| Όνομα, τίτλος, βασικά στοιχεία του site | `site.ts` |
| Υπηρεσίες | `services.ts` |
| Άρθρα (τα αλλάζει και ο γιατρός από το `/admin`) | `articles.json` |
| Ανακοινώσεις αρχικής (τις αλλάζει ο γιατρός από το `/admin`) | `announcements.json` |
| Βιογραφικό | `doctor.ts` |
| Κουμπιά και μικρά κείμενα (EL/EN) | `dictionary.ts` |
| Όροι χρήσης | `terms.ts` |

Μετά την αλλαγή αρκεί ένα `git push` για να ενημερωθεί το site.

## 7. Γνωστές σημειώσεις

- **Χάρτης Google.** Ο χάρτης στην αρχική και στην Επικοινωνία φορτώνει από την Google, η οποία
  μπορεί να βάλει cookies. Για αυστηρή συμμόρφωση με το GDPR μπορεί να γίνει «φόρτωση με κλικ».
- **Άρθρα.** Τα 7 παλιά υπάρχουν μόνο στα ελληνικά. Στην αγγλική και στη γερμανική έκδοση
  εμφανίζεται σχετική ενημέρωση. Τα νέα άρθρα μπορούν να έχουν και αγγλικό κείμενο από το admin.
- **Γερμανικά και admin.** Το admin έχει πεδία μόνο για ελληνικά και αγγλικά. Στη γερμανική σελίδα,
  άρθρα, ανακοινώσεις και διεύθυνση εμφανίζονται στα αγγλικά (ή στα ελληνικά αν δεν υπάρχουν αγγλικά).
- **Φωτογραφίες άρθρων.** Είναι από Freepik και Unsplash, με αναφορά της πηγής, όπως και στο
  παλιό site.
